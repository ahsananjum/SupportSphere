## Common failure and control coverage

Every relevant row includes happy path, permission/tenant denial, failed/unavailable vs empty state, pending/success/retry, retained input and current-state checks. Automated effects additionally cover duplicate/reordered events, disabled/revoked/stale work, bounded retries/lease recovery, terminal outcome and deduped exceptions. UI rows include applicable six-width, long-content, keyboard/focus/reduced-motion and visual review. No mocked provider or hidden UI button proves backend/provider safety.

Evidence status: NOT_RUN / PASS / FAIL / BLOCKED / NOT_APPLICABLE_WITH_REASON. Required blocked/not-run evidence prevents phase completion. U0–U5 use their scoped local/isolated proof; actual provider/deployed proof is assigned to U6.7. Preserve unexecuted owner/AI result sheets; add mappings when implemented controls change.
