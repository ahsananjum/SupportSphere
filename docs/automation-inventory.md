## Engineering verification foundation

`node scripts/verify-upgrade.mjs --phase U0 --layer docs|unit|isolated|browser|gate` selects bounded checks. Optional `--slice U0.N` narrows mapped unit coverage; isolated/browser layers run their shared U0 journeys. Output JSON in ignored `test-results/upgrades/` records timestamp, HEAD, worktree digest, target, commands, durations, exit states and limitations. A runner artifact never changes progress to COMPLETE.

- `docs`: validates roadmap/progress/test/prompt coverage, status vocabulary, local Markdown links and actual U0 test files/IDs. Markdown links containing route parentheses are supported.
- `unit`: mapped Vitest regressions plus `node --test tests/upgrade/verification.test.mjs` intentional failure checks.
- `isolated` / `browser`: require `RUN_UPGRADE_LOCAL=1` and the local CLI's actual loopback target on port 54321. No `.env` parsing, hosted project-ref override or production fallback. Local keys stay in process memory; command artifacts omit environment values.
- `gate`: bounded typegen/TypeScript/lint/format/unit/build checks. Browser/integration and explicit Markdown formatting remain separate required exit checks; the gate does not imply them.

Local startup uses committed `supabase/config.toml`, fixed project ID `supportsphere-u0-local`, separate `.next-u0` output and explicit local CSP connect sources only when `RUN_UPGRADE_LOCAL=1`. The existing app's dev output/server is preserved. Local fixture cron jobs are disabled deliberately for deterministic worker tests; worker batch/processor calls are explicit and bounded. No hosted scheduler is changed.

Fixtures use synthetic `u0-*` identities and exact created workspace/user IDs; cleanup removes fixture audit/membership rows before workspace deletion to respect the existing retention foreign keys. Inspect pending fixture records/processes before replay. Startup, migration/reset and generated types are explicit operations, never hidden runner side effects. No migration/reset/merge/deploy, provider message, secret rotation or recurring Codex job is launched by this runner.

Fresh replay exposed two baseline portability defects: the hosted-only `rls_auto_enable` revoke needed an existence guard, and P10's previously-created webhook trigger function needed CREATE OR REPLACE. These edits preserve the intended hosted result and allow a fresh isolated database to replay history; they are not remote migration-history repairs.
